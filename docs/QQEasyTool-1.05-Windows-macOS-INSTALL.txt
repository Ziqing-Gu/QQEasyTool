macOS: macOS 11 or later; match the host's running architecture.

2. Choose the correct archive
QQEasyTool-Windows-x64-1.05.zip — Windows x64 VST3
QQEasyTool-macOS-Apple-Silicon-1.05.zip — native Apple Silicon arm64 VST3
QQEasyTool-macOS-Intel-1.05.zip — Intel x86_64 VST3, also for an x86_64/Rosetta host on Apple Silicon
QQEasyTool-macOS-AU-Universal-1.05.zip — Universal 2 AU with both arm64 and x86_64; use AU for Logic Pro
Install only the formats you need. Select exactly one Mac VST3 architecture; do not install both. No Linux package is provided.

3. Windows installation / upgrade
1) Completely quit Cubase, Nuendo, REAPER, Studio One and every other plug-in host/scanner.
2) Extract QQEasyTool-Windows-x64-1.05.zip. The root must contain the complete QQEasyTool.vst3 folder.
3) Copy that entire folder into:
   C:\Program Files\Common Files\VST3
   Administrator approval may be needed. Replace the corresponding existing files. Do not create two nested folders with the same .vst3 name.
4) The plug-in filename has not changed. Remove old/duplicate copies from other scanned locations while hosts are closed, then copy the new version.
5) Reopen the host and rescan/reactivate VST3. If an old version remains visible, check duplicate scan paths, restart the host, and follow its documented plug-in-cache reset procedure.
If Windows blocks the downloaded ZIP, unblock it in file Properties and extract again.

4. macOS VST3 installation / upgrade
1) Quit all DAWs. Check whether the host runs as native arm64 or Intel/Rosetta x86_64; select only one matching VST3 ZIP.
2) Extract and copy the complete QQEasyTool.vst3 bundle into the user folder:
   ~/Library/Audio/Plug-Ins/VST3
   Or the system folder, which may require administrator approval:
   /Library/Audio/Plug-Ins/VST3
   Use Finder > Go > Go to Folder and enter the path. Holding Option in Finder's Go menu also reveals the user Library.
3) Keep only one copy of this format across user/system folders. With all hosts closed, move old/duplicate copies out before installing the new version.
4) Reopen the DAW and rescan VST3; restart the computer if necessary.

5. macOS AU installation / upgrade
Extract QQEasyTool-macOS-AU-Universal-1.05.zip and copy the complete QQEasyTool.component into:
~/Library/Audio/Plug-Ins/Components
or /Library/Audio/Plug-Ins/Components (administrator approval may be needed).
AU and VST3 are separate formats. Install only what you need; avoid duplicates of the same format in user/system folders.
Logic Pro does not load VST3. After installing AU, use Logic Pro's Plug-in Manager to reset/rescan QQEasyTool; other hosts provide their own Audio Units rescan.
For third-party ARA AU workflows unavailable in native mode, follow the host's requirements for running Logic Pro under Rosetta and rescan. This is not a claim of new Logic/ARA host testing.

6. macOS security and loading problems
Mac packages are ad-hoc signed, not Apple Developer ID signed or notarized. Download quarantine can block scanning.
First try allowing the plug-in in System Settings > Privacy & Security. Only for a trusted download from this repository, apply the commands to the actual installation location:
xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/VST3/QQEasyTool.vst3"
xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/Components/QQEasyTool.component"
For system-wide locations, only if installed there:
sudo xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/QQEasyTool.vst3"
sudo xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/Components/QQEasyTool.component"
Do not remove quarantine from files of uncertain origin. Quit/reopen the host, rescan, and restart the computer if needed.

7. Version behavior, manuals and validation limits
Ordinary VST3: click the waveform while stopped, then press Play to start the selected audio. Pause/resume in place retains audition. A later DAW relocation or cycle wrap clears the audition offset/internal loop and realigns both cursor and audio with the project. A new host-reported stopped location also cancels a pending selection.
ARA playback/processing is unchanged. Ordinary VST3 and ARA share the plug-in binary but use different host workflows.
As requested, no separate user manual is included. See this installation guide and the repository README for basic operation and changes.
Windows regression/loading checks passed. Mac build, architecture and signature verification records are supplied with the release. Build checks are not real macOS/ARA host acceptance.
